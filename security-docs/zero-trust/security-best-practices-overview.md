# Microsoft security best practices

Microsoft security best practices are designed to help organizations protect their digital estates by reducing risk, improving resilience, and enabling secure productivity. 

- At the core of these practices is the Zero Trust security model, which assumes that threats can exist both inside and outside the network.
- Zero Trust emphasizes verifying every access request, enforcing least privilege access, and segmenting resources as we assume breach.

Zero Trust principles are reinforced through a combination of engineering best practices, frameworks, benchmarks, and assessment tools.

- **[Microsoft Secure Future Initiative](/sfi/centralize-access-to-security-logs.md)**
- 
- (sfi/secure-future-initiative-overview.md)** focuses on Microsoft efforts to increasingly secure the way in which Microsoft designs, builds, tests, and operates its products. It also provides a series of best practice patterns that you can follow. The SFI initiative is broken down into pillars. Objectives for each pillar align to one or more [NIST Cybersecurity Framework functions](secure-future-initiative-overview.md#sfi-pillars-zero-trust-and-nist).
- **[Microsoft Entra security recommendations](/entra/fundamentals/configure-security)** provide a series of best practices that map to SFI themes. You can use the [Zero Trust Assessment tool](assessment/overview.md) to assess your identity environment against these best practices. 
- **[Microsoft Intune security recommendations](/intune/intune-service/protect/zero-trust-configure-security)** provide a series of best practices that map to SFI themes. You can use the [Zero Trust Assessment tool](assessment/overview.md) to assess your device security posture against these best practices.
- **[Azure networking security best practices](/azure/networking/security/zero-trust-network-security)** provide a series of best practices that map to SFI themes. You can use the [Zero Trust Assessment tool](assessment/overview.md) to assess your device security posture against these best practices.
- **[Data security best practices](/purview/zero-trust-microsoft-purview)** provide a series of best practices that map to SFI themes. You can use the [Zero Trust Assessment tool](assessment/overview.md) to assess your device security posture against these best practices.
- The **[Microsoft Cloud Security Benchmark (MCSB)](/security/benchmark/azure/overview)** provides a series of best practices and recommendations for improving the security of workloads, data, and services on Azure. 
- Other Microsoft Defender products and Microsoft Purview Compliance Manager also monitor and assess your enterprise security posture, providing actionable security and compliance insights and recommendations.
- External best practices and framework also emphasize Zero Trust security principles. [Learn more](security-zero-trust-frameworks.md).
