# Microsoft security documentation

Welcome to the open-source documentation for [Microsoft security](https://learn.microsoft.com/security/). This repository holds the source for the security docset published to [Microsoft Learn](https://learn.microsoft.com/security/), covering guidance such as Zero Trust, ransomware protection, security operations, security engineering, and securing AI.

Review this README file to understand how you can contribute to the documentation.

## Getting started

Contributing to open source is more than just providing updates. It's also about letting us know when there's an issue. To learn more, read our [Contributing guidance](CONTRIBUTING.md).

### Prerequisites

You decided to contribute. That's great! To contribute to the documentation, you need a few tools.

#### GitHub

Contributing to the documentation requires a [GitHub account](https://github.com/). If you don't have an account, follow the instructions for [GitHub account setup](https://learn.microsoft.com/contribute/get-started-setup-github) in our contributor guide.

#### Tools

To install the necessary tools, follow the instructions for [Install content authoring tools](https://learn.microsoft.com/contribute/get-started-setup-tools) in our contributor guide.
