# Microsoft Defender Challenge

![Security credentials banner with text that says defend skill up get certified.](/security/media/challenge/hero-credentials-with-text.png)

Complete the Microsoft Defender Skilling Challenge and submit an entry for a chance to win one of 500 50%-discounted SC-200 or SC-500 Microsoft Certification exam vouchers. Challenge entry period: July 20-August 21, 2026.

> [!div class="nextstepaction"]
> [Start the challenge](/challenges/6381s7tkn541nz)

## About the challenge

The Microsoft Defender Skilling Challenge is your opportunity to deepen your expertise across the Microsoft Defender product family - including Microsoft Defender XDR, Microsoft Sentinel, and Microsoft Defender for Cloud. Work through curated learning modules, sharpen your security skills, and enter the sweepstakes for a chance to earn a discounted Microsoft Certification exam voucher toward the SC-200 or SC-500 exam.

## How to enter

No purchase necessary.

Steps:

1. Register for and complete the Microsoft Defender Skilling Challenge on Microsoft Learn before August 21, 2026 at 11:59 PM UTC. 
1. After completing the challenge, submit your entry via the official sweepstakes entry form before the deadline. 
1. If selected as a winner, you will be contacted by MindhubPro by Pearson VUE via email with your voucher code and redemption instructions.  

> [!div class="nextstepaction"]
> [Submit your entry](https://forms.office.com/Pages/ResponsePage.aspx?id=v4j5cvGGr0GRqy180BHbR-BLGqyJXPlNlWysrop3YH1UQ1FCWDdNOUhOSFgwTE80UUpCUzFUQ1hRUi4u)

Get started with the topics covered in the challenge. Each card links to official Microsoft Learn content.

### Prepare for the SC-500 certification

Get exam-ready for the Cloud and AI Security Engineer Associate certification. Build expertise in securing cloud workloads, managing AI security risks, and implementing Zero Trust principles across the Microsoft security platform.

[Learn more](/credentials/certifications/cloud-and-ai-security-engineer-associate/?practice-assessment-type=certification)

### Stay current with Microsoft Defender XDR

Keep pace with the latest innovations in Microsoft Defender XDR - new detection capabilities, unified incident response features, and expanded coverage across identities, endpoints, email, and cloud apps.

### Microsoft Sentinel best practices

Explore expert guidance for deploying and operating Microsoft Sentinel at scale. From workspace architecture and data connector strategies to analytics rules and incident response workflows - build a mature SIEM/SOAR practice.
